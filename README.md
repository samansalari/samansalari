## Things I've built

- **[VotePulse](https://votepulse.je)** ([code](https://github.com/samansalari/JerseyIsland-2026)): non-partisan information site for Jersey's 2026 General Election. Candidate profiles, manifesto summaries that one model writes and a second model fact-checks, side-by-side comparison on 10 policy issues, and a public polling page. Next.js, Postgres, Drizzle, Railway.
- **[Comfy-workflow-builder](https://github.com/samansalari/Comfy-workflow-builder)**: a skill for Claude Code and Cursor that builds and debugs ComfyUI workflow JSON, checking nodes against the running server's schema instead of guessing.
- **[Openclaw-N8N](https://github.com/samansalari/Openclaw-N8N)**: lets an agent create, debug and monitor workflows on an n8n instance through its REST API.
- **[virtual-fitter-api](https://github.com/samansalari/virtual-fitter-api)**: virtual fitting backend for Kits.Style.
- **[cardiocare-signal-sample](https://github.com/samansalari/cardiocare-signal-sample)**: a public sample of the backend and ML code behind CardiocareAI.
